# Izvorni Podatki

- `de_eng-deu.json`: izvorni angleško-nemški nabor, uporabljen pri začetni izdelavi.
  Prvotno navedeni vir: [Dictionaries for the Onyx Boox e-reader](https://blog.jirivanek.eu/en/2023/11/24/dictionaries-for-the-onyx-boox-e-reader/).
- `output_wordnet.json.zip`: prvotni arhiv podatkov WordNet.
- `all_words.json`: izvorni seznam iz projekta
  [an-array-of-english-words](https://github.com/words/an-array-of-english-words).

To niso dodatne delovne kopije končnih slovarjev. Pri čiščenju so bile datoteke
samo premaknjene; njihova vsebina ni bila spremenjena. Za običajno uporabo ali
ponovni izvoz slovarjev niso potrebne.

Navedbe virov za samodejno dodane slovensko-srbske pregibne oblike so ločeno
ohranjene v `slo_ser_sources.json` in `review/inflections/`.
